Concepts

Closure

Each task stores its execution counter inside a closure, making the counter private.

Promise

Promises simulate asynchronous loading and can either resolve successfully or reject with an error.

Async/Await

Async functions allow asynchronous code to be written in a readable sequential style.

Event Loop

The Event Loop moves ready callbacks from queues to the Call Stack when it becomes available.
